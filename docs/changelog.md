# Changelog

All notable changes to this project are documented in the
[CHANGELOG.md](https://github.com/your-org/sdlc/blob/main/CHANGELOG.md) file
in the repository root.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Summary

### [0.4.0] - 2026-06-05

M4 milestone: packaging, distribution, and community infrastructure.

- Homebrew formula for macOS installation
- PyPI-ready package configuration
- GitHub issue and PR templates
- MkDocs documentation site with API reference

### [0.3.0-rc] - 2026-06-05

- 18 technology adapters with auto-detection
- 27 rules across 9 rule sets
- 4 rule enforcers (CR, Lint, CI, Runtime)
- 5 quality gates
- 11 subagent prompts
- SdlcClient Python API
- Real pipeline execution with RunCoordinator
- 965 tests with 92% code coverage

### [0.2.0] - 2026-05-15

- KB Scanner and Reconciler
- Stage and gate YAML templates
- CostTracker
- E2E tests
- Stage runner with gate evaluation

### [0.1.0] - 2026-04-01

- 13 packages, 19 CLI commands
- Dual LLM provider support
- Audit trail, state management
- 4-layer config system
